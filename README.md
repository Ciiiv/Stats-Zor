# Stats-Zor

Two-way NHL player analysis that runs entirely in the browser. Search any skater, compare two players head to head, and see careers across eras. It covers forwards and defensemen.

**Live site:** `https://ciiiv.github.io/Stats-Zor/` once GitHub Pages is on.

## What's on the page

- **Profile:** season line, defense, offense and role scores, trophies.
- **Two-way composite:** ranking against the same position group with adjustable defense, offense and role weights.
- **Stat board:** color-coded percentile matrix. Add or remove any player.
- **Head to head:** percentile radar plus a side-by-side table.
- **Shot environment:** expected goals for and against, and zone starts against relative impact.
- **Linemates and partners:** 5v5 results with and without each teammate.
- **Team swap:** projects a player's on/off impact onto another team.
- **Role and fit:** how a player was deployed game by game (line or pair, PP and PK unit, zone starts), how he did in each role against the league average for that role, and where his results say he fits.
- **Team deployment card:** every regular on a team, used-as vs. plays-like, with flags.
- **Career vs. career:** era-adjusted totals, same-age comparisons, trophies and Cups.
- **Career arcs and comps:** every season by age, plus the closest historical comps.
- **Shot maps:** where each player shoots from compared with his position's average, and goals against expected goals by location.

## How the data works

Nothing runs on a server. `.github/workflows/update-data.yml` runs `scripts/build_data.py` every morning at 12:17 UTC. The script downloads the sources below, computes the stats, and commits small JSON files to `data/`. The page reads those files.

| Source | Used for |
|---|---|
| [MoneyPuck.com](https://moneypuck.com/data.htm) season summaries (2008-09 on) | Expected goals, on/off-ice impact, zone starts, lines and pairs |
| NHL stats API (`api.nhle.com`) | Every NHL skater season since 1917-18, bios, league scoring for era adjustment |
| NHL player API (`api-web.nhle.com`) | Trophies, Stanley Cups, Hall of Fame |
| MoneyPuck shot data (2008-09 on) | Shot maps |
| MoneyPuck game-by-game skater data (2008-09 on) | Deployment: roles, role splits, fit |

MoneyPuck data is free for non-commercial use with credit to MoneyPuck.com.

**Era adjustment:** points and goals are rescaled to a league that scores 6.0 goals per game:
`adjusted = actual × 6.0 ÷ that season's league goals per game`.

## Running the update yourself

- **Nightly:** runs on its own.
- **On demand:** Actions tab → **Update data** → **Run workflow**.
- **Full rebuild:** tick **full** when you run it. The first run needs this and takes about 20–40 minutes.
- **Locally:** `python scripts/build_data.py` (add `--full` to rebuild everything). It uses only the Python standard library.
